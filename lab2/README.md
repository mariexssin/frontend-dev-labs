## Логіка роботи та власник стану
- **Власник стану (`TrafficLights`)**: зберігає `currentSignal`, `orientation` та об'єкт лічильників `counts`.
- **Похідний інтерфейс**: `totalClicks` обчислюється як сума лічильників під час рендеру (`counts.red + counts.yellow + counts.green`), без окремого `useState`.
- **Події**: натискання на `Light` викликає `onSelect(color)`, що піднімає подію до `TrafficLights` для одночасного оновлення активного сигналу та статистики.
- **Орієнтація**: зміна напрямку не впливає на поточний стан лічильників та активного сигналу.
